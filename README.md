# Сытый самурай — доставка суши

Сайт доставки суши на Nuxt 4 с серверной частью на Nitro и базой данных SQLite (Prisma).

## Архитектура

- **Фронтенд**: страницы `меню`, `админка`, `главная`, `политика конфиденциальности`
- **Серверные API** (`server/api/`): меню, настройки доставки, корзина, авторизация, админка (только сервер, без клиентского `localStorage`)
- **База данных**: SQLite через Prisma. Данные: товары, категории, промокоды, настройки доставки, пользователи и сессии админки, корзины.
- **Сид**: заполняет БД начальными данными (товары, категории, промокоды, админ)

## Быстрый старт (локально)

1. **Установить зависимости**
   ```bash
   npm install
   ```
   `postinstall` автоматически сгенерирует Prisma-клиент.

2. **Настроить окружение** (файл `.env` уже создан при инициализации)
   ```env
   DATABASE_URL="file:./dev.db"        # путь к БД (относительно каталога схемы)
   ADMIN_USERNAME="admin"              # логин администратора для сида
   ADMIN_PASSWORD="admin123"           # пароль администратора для сида (смените!)
   SESSION_SECRET="..."                # не используется в текущей реализации, можно задать случайную строку на будущее
   ```

3. **Применить миграции и заполнить БД**
   ```bash
   npx prisma migrate dev   # применит миграцию и запустит сид (или: npm run db:seed)
   ```

4. **Запустить в режиме разработки**
   ```bash
   npm run dev
   ```
   Сайт доступен по адресу `http://localhost:3000/start/`

## Продакшен-сборка и запуск (локально)

```bash
npm run build
npm run start
```

> Скрипт `deploy` (GitHub Pages) оставлен, но сейчас не работает: статическая генерация несовместима с серверным API и базой данных.

## Админка (`/start/admin`)

- Вход по логину и паролю (по умолчанию `admin` / `admin123`, задаются через `.env` перед сидом)
- CRUD товаров: добавление, редактирование, удаление, сброс к сид-данным через кнопку «Сбросить к умолчанию»
- Категории и промокоды пока управляются только через сид
